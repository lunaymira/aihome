# Telegram Mini App · Счётчики дома

Приложение для учёта показаний счётчиков воды и электричества с автоматическим расчётом стоимости и проверкой квитанций.

## Возможности

✅ **Учёт показаний** — электричество, холодная и горячая вода  
✅ **Автоматический расчёт** — стоимость по каждому счётчику и общая сумма  
✅ **Сверка с квитанцией** — проверка правильности начислений  
✅ **История показаний** — все записи с детальной информацией  
✅ **Современный дизайн** — плавные анимации, удобный интерфейс  
✅ **Работает в Telegram** — запускается как Mini App без установки

## Как запустить

### 1. Создайте бота в Telegram

1. Откройте [@BotFather](https://t.me/botfather) в Telegram
2. Отправьте `/newbot` и следуйте инструкциям
3. Сохраните токен бота

### 2. Настройте Web App

1. Отправьте BotFather команду `/newapp`
2. Выберите вашего бота
3. Заполните информацию:
   - **Title**: Дом · Счётчики
   - **Description**: Учёт показаний счётчиков воды и электричества
   - **Photo**: Загрузите иконку (512×512 px)
   - **Demo GIF/Video**: Пропустите (опционально)

### 3. Разместите приложение

**Вариант A: GitHub Pages (бесплатно)**

1. Создайте репозиторий на GitHub
2. Загрузите все файлы (`index.html`, `style.css`, `app.js`)
3. В настройках репозитория включите GitHub Pages (Settings → Pages → Source: main branch)
4. Скопируйте URL: `https://ваш-username.github.io/название-репозитория`

**Вариант B: Netlify (бесплатно)**

1. Зарегистрируйтесь на [Netlify](https://www.netlify.com/)
2. Drag & drop папку с файлами на netlify.com/drop
3. Скопируйте полученный URL

**Вариант C: Vercel (бесплатно)**

1. Зарегистрируйтесь на [Vercel](https://vercel.com/)
2. Импортируйте репозиторий или загрузите файлы
3. Скопируйте полученный URL

### 4. Привяжите URL к боту

1. Вернитесь к BotFather
2. Отправьте `/myapps`
3. Выберите ваше приложение
4. Нажмите **Edit Web App URL**
5. Отправьте URL вашего приложения (из шага 3)

### 5. Готово! 🎉

Откройте бота в Telegram и нажмите на кнопку меню или отправьте любое сообщение — бот предложит запустить приложение.

## Как использовать

1. **Внесите показания** — дата, показания счётчиков, тарифы
2. **Нажмите "Рассчитать и сохранить"** — увидите расход и стоимость по каждому счётчику
3. **Введите сумму из квитанции** — приложение покажет, есть ли переплата/недоплата
4. **История показаний** — все прошлые записи доступны ниже

## Хранение данных

Все данные хранятся **локально в браузере Telegram** (localStorage). Данные не отправляются на сервер и доступны только вам.
